Detailed Description

Práctica 1 - Apartado 4: Protocolo de comunicación UART para el control de periféricos (ADC y PWM).

Implementa un protocolo de comandos por puerto serie para controlar la lectura del ADC y el ciclo de trabajo del PWM. Admite los siguientes comandos:

  • 'ADC': Muestra una lectura puntual del ADC.
  • 'ADC(x)': Configura el envío periódico del ADC cada 'x' segundos mediante Timer. Si x=0, detiene el envío.
  • 'PWM(x)': Cambia el Duty Cycle del PWM entre 0 y 9 (0% a 100%).
