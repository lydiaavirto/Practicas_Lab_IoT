Detailed Description

Práctica 1 - Apartado 5: Comunicación I2C Esclavo (ESP32-S3).

Configura la ESP32-S3 en modo esclavo I2C con la dirección 0x08. Registra un manejador de eventos por interrupción ('onReceive') que procesa los comandos recibidos desde el maestro (Arduino Nano) para conmutar un LED.

◆ receiveEvent()

void receiveEvent ( int howMany)

Rutina de servicio/callback de recepción I2C (ISR).

Se activa automáticamente en modo interrupción al recibir bytes desde el maestro. Lee los caracteres entrantes y conmuta el estado lógico del 'LED_PIN':

  • '1': Enciende el LED.
  • '0': Apaga el LED.
    Parameters
    howManyNúmero de bytes disponibles en el buffer de recepción I2C.
