Detailed Description

Práctica 1 - Apartado 3: Generación de señal PWM a 5 kHz proporcional a la lectura del ADC.

Utiliza la API de Mbed OS (PwmOut) para generar una salida PWM de 5 kHz en el pin D2. El ciclo de trabajo (Duty Cycle) de la señal varía de forma proporcional entre el 0% y el 100% según el valor leído en la entrada analógica A0.
