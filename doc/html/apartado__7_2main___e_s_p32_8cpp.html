Function Documentation

◆ callbackTimer()

void callbackTimer ( )

Rutina de servicio de la interrupción (Callback) del temporizador.

Se activa cada 200 ms durante la captura. Incrementa el contador de muestras y activa la bandera de transmisión al alcanzar 5 muestras (1 segundo).

◆ loop()

void loop ( )

Bucle principal de ejecución de la PLACA 1.

Atiende las órdenes del usuario por la UART para iniciar la captura a demanda, gestiona las lecturas de los 9 sensores cada 200 ms y envía por I2C la estructura binaria completa de 180 bytes a la PLACA 2 tras completar el segundo.

◆ setup()

void setup ( )

Configuración inicial del sistema, puerto serie, I2C Maestro e IMU.

Inicializa la consola serie a 115200 baudios, arranca la interfaz I2C Maestro (Wire), comprueba la conexión con la IMU LSM9DS1 y programa el temporizador a 200.000 µs (200 ms).
