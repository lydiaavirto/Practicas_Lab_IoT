Detailed Description

Práctica 1 - Apartado 5: Comunicación I2C Maestro (Arduino Nano 33 BLE).

Implementa la interfaz I2C Maestro para enviar comandos de control a un esclavo (ESP32-S3) con dirección 0x08. Envía alternativamente los caracteres '1' y '0' cada 2 segundos para encender y apagar un LED externo conectado en la placa esclava.

◆ loop()

void loop ( )

Bucle principal de ejecución del Maestro.

Genera tramas de escritura I2C dirigidas a la dirección 0x08:

  • Envía el carácter '1' para ordenar el encendido del LED.
  • Espera 2000 ms.
  • Envía el carácter '0' para ordenar el apagado del LED.
  • Espera 2000 ms.

void setup ( )

Configuración inicial de la comunicación serie e interfaz I2C Maestro.

Inicializa la consola a 115200 baudios y configura las líneas SDA (A4) y SCL (A5) en modo Maestro mediante la librería Wire.
